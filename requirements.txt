# Pinned deliberately. This file used to be completely unpinned, so every
# Streamlit Cloud rebuild re-resolved the whole tree to the newest releases -
# meaning a breaking release in any transitive dependency could take the live app
# down with no code change on our side. That is exactly how the app "worked
# yesterday" and then failed with:
#
#   TypeError: GZipResponder.__init__() missing 1 required keyword-only argument:
#   'thread_minimum_size'
#
# GZipResponder is a Starlette internal. Nothing in this repo touches gzip,
# Starlette, uvicorn or middleware - it arrives transitively and a new upstream
# release changed its signature.
#
# Upper bounds keep the next breaking major out while still allowing patches. To
# reproduce a known-good set exactly, read the resolved versions from the last
# successful Streamlit Cloud build log ("Installing dependencies") and pin to those.
